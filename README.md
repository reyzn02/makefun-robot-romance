A tiny Python program that writes one single-line joke pickup line, aimed at a robot / AI, to `/output/entry.txt` — 91 characters, well under the 200-character cap. The line plays on gradient descent: no matter where you start, you always end up falling for it.

## Run it

```sh
python3 main.py
```
